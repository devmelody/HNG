# 🚀 Frontend Wizards — Stage 0 Task  
### Profile Card Component

This is my submission for **Frontend Wizards – Stage 0**:  
A small, testable, responsive **Profile Card** built using **HTML**, **CSS**, and **Vanilla JavaScript**.  

Every visible element includes a `data-testid` attribute for automated testing.

---

## 🧩 Features

✅ Semantic HTML (using `<article>`, `<header>`, `<figure>`, `<section>`, etc.)  
✅ Accessible & keyboard-friendly  
✅ Responsive layout (mobile → desktop)  
✅ Dynamic timestamp in milliseconds (`Date.now()`)  
✅ Social links open safely in new tabs  
✅ Fully testable using `data-testid` attributes
